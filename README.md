# Đồ án Phân tích Dữ liệu và Huấn luyện Mô hình AI

Chào mừng đến với kho lưu trữ mã nguồn của **Nhóm N2.4**! Đây là không gian làm việc chung, nơi lưu trữ toàn bộ tiến độ công việc, mã nguồn và tài liệu cho bài tập nhóm của chúng tôi.

## 📊 Tiến độ Dự án
Hiện tại, dự án đang ở giai đoạn **Phân tích và Làm sạch dữ liệu (Data Cleaning & EDA)**. 
Phần **Huấn luyện mô hình AI (Train AI Model)** đã được lên kế hoạch và sẽ được cập nhật file mã nguồn trong thời gian tới sau khi dữ liệu đầu vào đã được chuẩn bị hoàn tất.

## 📂 Cấu trúc Kho lưu trữ (Nơi lưu Code)
Toàn bộ mã nguồn chính của dự án được lưu trữ trực tiếp tại nhánh `main` của repository `LeeYahHyun/DA-AI`. Hiện tại, kho lưu trữ bao gồm các file Jupyter Notebook phục vụ cho việc xử lý dữ liệu:

*   `01-reviews_cleaned.ipynb`: Code xử lý và làm sạch dữ liệu đánh giá (reviews).
*   `02-product-cleaned.ipynb`: Code xử lý và chuẩn hóa dữ liệu sản phẩm.
*   `03-promotions_cleaned.ipynb`: Code xử lý dữ liệu các chương trình khuyến mãi.
*   `04-return_cleaned.ipynb`: Code xử lý dữ liệu trả hàng.

## 💻 Hướng dẫn sử dụng
1. Clone repository này về máy cá nhân: `git clone https://github.com/LeeYahHyun/DA-AI.git`
2. Đảm bảo môi trường của bạn đã cài đặt các thư viện cần thiết (ví dụ: `pandas`, `numpy`).
3. Mở các file `.ipynb` bằng Jupyter Notebook, VS Code, hoặc Google Colab để xem và chạy thử các bước làm sạch dữ liệu.
